# Documentos acadêmicos

Esta pasta reúne os documentos e as evidências da atividade da disciplina de
Qualidade de Software sobre refatoração de test smells no projeto `book-to-skill`.

## Arquivos

- `DIARIO_DE_BORDO.md`: versão principal, navegável e revisável no GitHub.
- `DIARIO_DE_BORDO.pdf`: cópia do documento produzido para entrega.

## Separação do pull request

Estes documentos pertencem somente à branch `evidencias-academicas`. Eles não
fazem parte da branch `refatoracao-final` nem do pull request enviado ao
repositório original, cujo diff permanece limitado aos testes refatorados.
